# Relatório de User Stories — Guião W3

## Ator: Cliente

| User Story | Descrição | Prioridade | Implementado |
|---|---|---|---|
| USR1 | Como cliente quero fazer login na aplicação para aceder à minha conta | Médio | 100% |
| USR2 | Como cliente quero registar uma conta para poder comprar bilhetes | Médio | 100% |
| USR3 | Como cliente quero listar os eventos disponíveis para escolher um evento | Alto | 100% |
| USR4 | Como cliente quero ver os detalhes de um evento (data, sala, preços, disponibilidade) | Alto | 100% |
| USR5 | Como cliente quero comprar bilhetes online para assistir a eventos | Alto | 100% |
| USR6 | Como cliente quero receber a confirmação da compra com referência | Alto | 100% |
| USR7 | Como cliente quero consultar o histórico das minhas compras | Médio | 100% |
| USR8 | Como cliente quero filtrar eventos por nome, data e categoria | Baixo | 100% |

## Ator: Administrador

| User Story | Descrição | Prioridade | Implementado |
|---|---|---|---|
| USA1 | Como administrador quero criar novos eventos com tarifários | Alto | 100% |
| USA2 | Como administrador quero editar eventos existentes | Alto | 100% |
| USA3 | Como administrador quero cancelar eventos | Alto | 100% |
| USA4 | Como administrador quero ver estatísticas de vendas no dashboard | Médio | 100% |
| USA5 | Como administrador quero listar e filtrar todos os eventos por estado | Médio | 100% |

## Ator: Vendedor

| User Story | Descrição | Prioridade | Implementado |
|---|---|---|---|
| USV1 | Como vendedor quero emitir bilhetes presencialmente ao balcão | Alto | 100% |
| USV2 | Como vendedor quero consultar a disponibilidade dos eventos em tempo real | Alto | 100% |
